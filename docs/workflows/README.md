# Optional workflow patterns

Copy and adapt only the workflows you expect to repeat. They require no particular services or scripts.

To install one workflow, copy its file and any linked template. Draft tracking requires both `draft-tracking.md` and `draft-ledger.md`.

| Workflow | Use it for |
| --- | --- |
| [Draft tracking](draft-tracking.md) | Preserving exact draft versions for later comparison. |
| [Email composition](email-composition.md) | Checking recipient intent, message structure, and saved formatting. |
| [File triage](file-triage.md) | Planning and recording file moves with collision checks. |

Each workflow needs owner-authored authorization rules. A checklist or ledger does not grant permission to access accounts, send messages, or change files.
